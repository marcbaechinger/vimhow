# VimHow

> **⚠️ Deprecated**
>
> This project is deprecated and is no longer continued. It is not actively
> maintained, and no further updates, bug fixes, or support will be provided.

VimHow was an AI-powered Vim tutor plugin that used the Gemini API to answer
Vim-related questions inside Vim. The old documentation is still available in
[`doc/vimhow.txt`](doc/vimhow.txt), but it is provided for historical reference
only.
